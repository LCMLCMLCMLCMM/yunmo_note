# YunmoNote

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)

**YunmoNote** is a simple yet powerful text editor designed for efficiency and ease of use. Whether you're writing code, taking notes, or drafting documents, YunmoNote provides a clean, distraction-free environment with essential features to boost your productivity.

## Features

- **Clean & Minimal Interface**: Focus on your content without distractions.
- **Powerful Editing Tools**: Syntax highlighting, search & replace, line numbering, and more.
- **Offline-First Design**: All core services run locally on your device for maximum privacy and reliability.
- **Lightweight & Fast**: Built for performance, starts instantly and runs smoothly.
- **Customizable Themes**: Personalize your workspace with light and dark themes.
- **In-App Sponsorship**: Support the project directly from within the application.

## Getting Started

### Installation

1. Download the latest version from the [Releases](https://github.com/LCMLCMLCMLCMM/yunmo_note/releases) page.
2. Install the application based on your operating system (Windows, macOS, Linux).
3. Launch YunmoNote and start writing!

### Usage

- Open or create a new file with `Ctrl+N` / `Cmd+N`.
- Save your work with `Ctrl+S` / `Cmd+S`.
- Use `Ctrl+F` / `Cmd+F` to search within the document.
- Enable/switch themes in **Settings > Appearance**.

- All other functionalities operate offline — your data stays under your control.
